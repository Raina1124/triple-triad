幻卡卡面模板抓取工具

流程：① 抓取並打包 → 從 FFXIV Collect API 取得全卡清單、逐張下載卡圖、灰階縮放進雪碧圖 → ② 下載 templates.png 與 templates.json，放進分析台專案的 public/templates/。
若卡圖因 CORS 無法用網路模式取得（記錄會顯示紅字），改用「本機檔案模式」：先以其他方式把卡圖存到本機資料夾 （檔名須為 {id}.png），再用檔案選取器一次選入全部。
批次下載法：按「下載網址清單」取得 urls.txt，在同資料夾執行 PowerShell：
Get-Content urls.txt | ForEach-Object { $p = $_ -split ' ', 2; Invoke-WebRequest $p[1] -OutFile "$($p[0]).png"; Start-Sleep -m 100 }
注意：不要用 file:// 直接開這個檔（跨域請求會被擋，出現 Failed to fetch）。 請放進專案 public/，以 npm run dev 後開 http://localhost:5173/fetch-templates.html。
若 API 清單仍抓不到，可改貼 id 清單（從 cards-data.ts 取，在專案目錄的瀏覽器 console 或 node 執行： CARD_POOL.map(c => c.id).join(',')），工具會用固定網址格式 ffxivcollect.com/images/cards/large/{id}.png 直接抓圖。
